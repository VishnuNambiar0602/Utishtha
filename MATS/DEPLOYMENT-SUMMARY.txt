================================================================================
                         🚀 3-STEP DEPLOYMENT
================================================================================

STEP 1: SETUP SUPABASE (Database)
----------------------------------
→ Go to: https://supabase.com
→ Create project
→ Run schema.sql in SQL Editor
→ Create "medical-reports" storage bucket
→ Copy API keys

Time: 15 minutes
Cost: FREE

STEP 2: DEPLOY GRASP2026 BACKEND (Medical AI)
----------------------------------------------
→ Create EC2 instance (t2.medium)
→ SSH into server
→ Upload code
→ Install Python dependencies
→ Setup Gunicorn + Nginx
→ Start service

Time: 45 minutes
Cost: ~$34/month (or $8/month for t2.micro)

STEP 3: DEPLOY MATS FRONTEND (Website)
---------------------------------------
→ Create .env file with API keys
→ Run: npm run build
→ Create S3 bucket
→ Upload dist/ folder
→ Create CloudFront distribution
→ Test website

Time: 30 minutes
Cost: ~$5/month
