## 🔑 Required Credentials

Create a `.env` file in the MATS folder:

```bash
# Google Gemini API
VITE_API_KEY=your_gemini_api_key
GEMINI_API_KEY=your_gemini_api_key

# Supabase
VITE_SUPABASE_URL=https://xxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

# GRASP2026 Backend (your EC2 IP)
VITE_GRASP2026_API_URL=http://54.123.45.67
```

## 📦 Deployment Commands

### Frontend (MATS)
```bash
# Navigate to MATS folder
cd MATS

# Install dependencies
npm install

# Build for production
npm run build

# Deploy to S3 (after creating bucket)
aws s3 sync dist/ s3://your-bucket-name/ --delete

# Invalidate CloudFront cache
aws cloudfront create-invalidation \
  --distribution-id YOUR_DIST_ID \
  --paths "/*"
```

### Backend (GRASP2026)
```bash
# SSH into EC2
ssh -i your-key.pem ubuntu@your-ec2-ip

# Navigate to backend folder
cd ~/backend

# Activate virtual environment
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start service
sudo systemctl start grasp2026

# Check status
sudo systemctl status grasp2026
```

## 🆘 Troubleshooting

### Website not loading?
1. Check S3 bucket policy (public access)
2. Verify CloudFront distribution is deployed
3. Check browser console for errors (F12)

### Medical reports not generating?
1. Check GRASP2026 backend: `sudo systemctl status grasp2026`
2. Verify EC2 security group allows port 5000
3. Test API: `curl http://your-ec2-ip/health`

### Real-time updates not working?
1. Check Supabase credentials in .env
2. Rebuild and redeploy frontend
3. Check browser console for WebSocket errors
